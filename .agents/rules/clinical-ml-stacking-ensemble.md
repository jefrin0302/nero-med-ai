# Clinical Machine Learning & Stacking Ensemble Rules

## 1. Outlier-Resilient Clinical Preprocessing Invariant
- For medical tabular and laboratory datasets, numeric biomarkers (e.g., ALT, AST, Total Bilirubin, Ceruloplasmin, 24-hr Urinary Copper) must be preprocessed using:
  - `SimpleImputer(strategy="median")` for missing value handling.
  - `RobustScaler(quantile_range=(25.0, 75.0))` for numeric feature scaling.
- **NEVER** use `StandardScaler` (mean/std) or `MinMaxScaler` on hepatic enzymes or biomarkers prone to acute flare-ups (e.g., ALT $> 1500$ U/L). Extreme clinical spikes pull the sample mean and inflate standard deviation, squashing baseline variance into near-zero clusters.
- Categorical demographic features (`Sex`, `Region`, `Socioeconomic Status`, `Alcohol Use`) must be imputed with `SimpleImputer(strategy="most_frequent")` and encoded via `OneHotEncoder(handle_unknown="ignore", sparse_output=False)` within a unified scikit-learn `ColumnTransformer`.

## 2. 4-Model Complementary Paradigm Ensemble
The core disease prediction engine must employ four distinct mathematical learning paradigms:
1. **XGBoost Classifier (`XGBClassifier`):** Gradient-boosted decision trees sensitive to non-linear clinical thresholds and subtle biomarker cutoffs.
2. **Logistic Regression (`LogisticRegression`):** Balanced, calibrated reference statistical log-odds.
3. **Random Forest Classifier (`RandomForestClassifier`):** Bagged ensemble of decorrelated decision trees minimizing variance and handling clinical measurement noise.
4. **Support Vector Machine (`SVC(kernel="rbf", probability=True)`):** Maximum-margin hyperplanes mapping complex multi-organ biomarker interactions.

## 3. Strict Out-Of-Fold (OOF) Stacking & Isotonic Calibration
- The Stacking Meta-Classifier must **NEVER** be trained on predictions generated by base models on their own training data (which introduces severe target leakage and overfits to the most complex model).
- A 5-Fold Stratified Cross-Validation scheme must generate out-of-fold probability vectors $[p_{\text{xgb}}, p_{\text{logreg}}, p_{\text{rf}}, p_{\text{svm}}]$ upon which the meta-classifier (`LogisticRegression`) is fitted.
- The meta-model must be wrapped with an **Isotonic Calibration Layer** (`CalibratedClassifierCV(method="isotonic", cv="prefit")`) to guarantee that predicted probabilities reflect empirical epidemiological risk.

## 4. Multi-Model Telemetry & Explainability Invariants
- In SQLite database storage (`assessments` table), each assessment must persist individual model probabilities (`xgb_prob`, `logreg_prob`, `rf_prob`, `svm_prob`) in addition to the final consensus `probability`.
- In the user interface (`result.html`) and admin governance dashboard (`admin_dashboard.html`), all 4 models must display their individual percentage confidence scores.
- The Clinical Assistant RAG bot must cite individual model voting agreements when explaining the diagnostic risk assessment to clinicians.
- SHAP explainability (`KernelExplainer`) must evaluate over the full ensemble inference pipeline using authentic patient inputs.
